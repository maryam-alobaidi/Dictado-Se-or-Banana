## الوضع الحالي للمستودع

- الحالة: !`git status --short`
- الفرع الحالي: !`git branch --show-current`
- المستودع البعيد: !`git remote -v`
- آخر التغييرات: !`git diff --stat`

## المطلوب

افتح طلب دمج على GitHub للتغييرات الحالية باتباع هذه الخطوات بالترتيب:

### 1. التحقق
- إذا لم يكن هناك مستودع بعيد (remote)، توقف وأخبرني بالعربي.
- إذا لم تكن هناك أي تغييرات، أخبرني أنه لا يوجد شيء لرفعه وتوقف.
- نفّذ `gh auth status`. إذا كانت أداة `gh` غير مثبتة أو غير مسجلة الدخول، توقف واشرح لي بالعربي كيف أثبتها وأسجل الدخول بالأمر `gh auth login`.

### 2. الفرع
- اعرف اسم الفرع الرئيسي بالأمر `gh repo view --json defaultBranchRef -q .defaultBranchRef.name`.
- إذا كنت على الفرع الرئيسي، أنشئ فرعاً جديداً بالأمر `git switch -c <اسم>`:
  - الاسم بالإنجليزية، قصير، بأحرف صغيرة وشرطات، ويبدأ بنوع التغيير، مثل:
    `feature/add-app-icons` أو `fix/login-error` أو `docs/update-readme`.
  - استخرج الاسم من وصفي: $ARGUMENTS، وإذا لم أكتب وصفاً فاستخرجه من الـ diff.
- إذا كنت أصلاً على فرع جانبي، ابقَ عليه.

### 3. الـ commit والرفع
- نفّذ `git add -A`.
- اكتب رسالة commit قصيرة وواضحة بالإنجليزية تصف التغيير.
- نفّذ `git commit` ثم `git push -u origin <اسم الفرع>`.
- لا تستخدم `--force` أبداً. إذا فشل الرفع، اشرح لي السبب بالعربي.

### 4. طلب الدمج
- نفّذ `gh pr create` نحو الفرع الرئيسي، مع:
  - عنوان قصير وواضح بالإنجليزية.
  - وصف بالإنجليزية يحتوي على: ماذا تغيّر، ولماذا، وقائمة بالملفات الأساسية التي تغيّرت.
- لا تدمج الطلب بنفسك أبداً. الدمج قراري أنا بعد المراجعة.

### 5. الملخص
في النهاية أعطني ملخصاً قصيراً بالعربي فيه:
- اسم الفرع الجديد.
- رسالة الـ commit.
- رابط طلب الدمج.
- تذكير بأن الخطوة التالية هي مراجعة الطلب على GitHub ثم دمجه.
